## ❗Problema: Ferramenta de Consulta de Personagens para Mestre de Jogo 📝

  - **Contexto:** *Supondo que você é o desenvolvedor de ferramentas para um novo RPG de fantasia. O Mestre do Jogo (Game Master) precisa de um programa de console simples para consultar rapidamente os dados dos personagens dos jogadores durante uma sessão ao vivo. Cada personagem possui uma ID única, um nome e três atributos principais: Força, Agilidade e Inteligência.*

## 📋 Requisitos

  - Use uma **struct** para representar os dados de um personagem (ID, nome, 3 atributos).
  - Armazene os personagens em um vetor de **structs.**
  - Implemente uma função de busca linear para encontrar um personagem pela sua ID.
  - O programa deve continuar oferecendo a opção de busca até que a opção '2' (Sair) seja selecionada.
