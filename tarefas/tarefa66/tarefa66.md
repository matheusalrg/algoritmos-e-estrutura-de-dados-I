## ❗Problema: Ordenação do Placar de Batalha 🤼‍♂️

  - **Contexto:** *Você está desenvolvendo um jogo de arena de batalha. Ao final de cada partida, o sistema precisa exibir o placar final, mostrando os jogadores ordenados da maior para a menor pontuação. Isso cria um ranking claro e incentiva a competição. Você foi encarregado de implementar a lógica de ordenação do placar.*

## 📋 Requisitos

  - O programa deve ler o número de jogadores N e, em seguida, as N pontuações.
  - É obrigatório o uso do algoritmo **Bubble Sort** para a ordenação.
  - A ordenação deve ser em ordem **decrescente**.
  - A saída final deve ser uma única linha contendo as pontuações ordenadas, separadas por um espaço. Por exemplo: 1500 1250 1100 980 750
